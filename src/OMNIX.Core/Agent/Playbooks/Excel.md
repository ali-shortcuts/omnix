EXCEL WORK GUIDE
Read the document map and the intended cells first. A follow-up edits the same sheet. A shop/seller name requested ABOVE a table is a separate title frame, never a repeated data column. For new titled tables default title A1:lastColumn2, spacer row3, headers row4, data row5. Respect explicit coordinates. For an existing table inspect occupied cells before moving anything; do not merge over data. Use sheet.heading only in a safe title area.
Store numbers as numbers, dates as dates and formulas as typed formulas. Derive references from actual data rows. Check representative inputs, exact formula AND independently computed result, native table range, and title outside table. Do not multiply weight by purity again when the supplied rate already applies to that purity. Label sample data and unknown shop names honestly. Use readable widths, wrapped headings, suitable row heights, RTL/Dari and AFN according to configured locale, not forced centering of every value. Check both native content and visual layout when image input is supported. Never infer all workbook data from the selection alone.
